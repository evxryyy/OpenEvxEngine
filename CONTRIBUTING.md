# Contributing

Thank you for your interest in contributing to this repository.

Whether you're reporting a bug, suggesting an improvement, or submitting code, every contribution is appreciated.

## Reporting Issues

Before opening a new issue, please check if it has already been reported.

When creating an issue, include:
- A clear description of the problem or suggestion.
- Steps to reproduce the issue (if applicable).
- Expected behavior.
- Actual behavior.
- Any relevant screenshots, logs, or code samples.

## Pull Requests

Before submitting a pull request:

- Ensure your changes are tested.
- Keep your changes focused on a single feature or fix.
- Follow the existing coding style.
- Update documentation when necessary.
- Make sure your changes do not introduce breaking changes unless previously discussed.

## Code Style

Please:
- Write clean and readable code.
- Keep naming consistent with the rest of the project.
- Avoid unnecessary complexity.
- Prefer performance and maintainability where appropriate.

## Feature Requests

Feature requests are welcome. If you plan to implement a large feature, consider opening an issue first so it can be discussed before development begins.

## Questions

If you have any questions regarding the repository or a specific project, feel free to open a discussion or an issue.

Thank you for helping improve this repository.
