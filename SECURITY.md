# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please do **not** open a public issue.

Instead, contact me privately through one of the following:

- GitHub: Open a private security advisory if available.
- X : https://x.com/Dummy_yysl
- Ko-fi: https://ko-fi.com/evxryyy

Please include:

- A description of the vulnerability.
- Steps to reproduce it.
- The affected project or package.
- Any proof of concept, if applicable.

I will investigate the report as soon as possible and work on a fix if the issue is confirmed.

Thank you for helping keep this repository secure.
